# Premium Electronics Store

A premium electronics ecommerce website built with Next.js. Includes a landing page, product listing, cart, login/signup, checkout, and admin dashboard UI.

## Features
- Premium electronics brand experience
- Responsive home page and product catalog
- Search and category filters
- Shopping cart with quantity updates and totals
- Login/signup UI
- Checkout with payment option selection
- Admin dashboard summary cards

## Tech Stack
- Next.js
- React
- CSS Modules/Global CSS

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production Deployment
You can deploy this project to Vercel or any Node.js hosting platform.
